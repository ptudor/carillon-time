Carillon 1.0 is a pure-Go NTP time daemon for Linux and FreeBSD, with GPS and
serial PPS inputs, an inspectable discipline loop, and an embedded monitoring
interface. It ships with `carillonctl` for local control and status.

### Downloads

| Platform | Architectures | Files |
| --- | --- | --- |
| Linux | amd64, arm64 | `.tar.gz`, `.rpm`, `.deb` |
| FreeBSD | amd64, arm64 | `.tar.gz` with deployment examples |

Every archive and Linux package contains both `carillon` and `carillonctl`.
RPMs and DEBs are unsigned. Check the SHA-256 manifest and GitHub build
attestation before installation.

Packages install with network-only client defaults and do not start or enable
Carillon. Configure your upstreams and explicitly arrange the handover from any
existing time service before activating it. See the
[Linux setup guide](https://github.com/ptudor/carillon-time/blob/v1.0.0/docs/linux-packages.md).

You can inspect an NTP server without changing the local clock:

```sh
carillon -version
carillon query -timeout 5s pool.ntp.org
```

### Verification and scope

CI runs native race tests on Linux amd64, Linux arm64, and macOS arm64, safe ABI
checks where supported, every release cross-build, Debian 13/Fedora 43 package
lifecycle tests, vulnerability scans, and full-history secret scans. These tests
do not adjust the host clock or access reference-clock hardware.

FreeBSD release binaries are cross-compiled. Hardware accuracy depends on the
receiver, PPS path, kernel, and deployment; this release does not make a measured
accuracy guarantee. NTS, PTP, and hardware NIC timestamping are outside its scope.
